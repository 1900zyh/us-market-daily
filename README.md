# 美股观察 · Market Pulse

面向 AI 产业的中文美股行情与每日情报网站，提供市场概览、未来七日信号、交易日异动分析及可配置的双 LLM 研究员。

默认聚焦 **AI 产业**：芯片算力、云平台、数据中心与 AI 应用，保留「全市场」切换与宏观背景。AI 观察池为人工维护的 35 只关联股票，独立筛选异动，避免被全市场样本的涨跌榜名额挤出。业务关联不表示纯 AI 收入。

## 启动

需要 Node.js 22 或更新版本，无需安装 npm 依赖。

双击 `start.bat`，或者在此目录运行：

```powershell
npm start
```

打开 http://localhost:4173。首次采集真实数据通常需要 15–60 秒，页面会自动显示结果。关闭浏览器不会停止后台服务；如果通过终端启动，关闭该终端会停止服务。更换端口：`$env:PORT=4174; npm start`。

## 每日更新

- 服务运行期间，每天北京时间 20:00（`Asia/Shanghai`，UTC+8）触发日报采集；通常几十秒后生成完成。
- 启动、跨日、手动点击「更新日报」时也会更新；错过当天 20:00 的任务会在恢复服务后补齐当日内容，无法追溯抓取停机时刻的历史信息。
- 日报保存到 `data/reports/YYYY-MM-DD.json`。同日以较新成功报告更新；部分失败不会覆盖原有的更完整归档。
- 可选：在 Codex 或操作系统调度器中设置每日北京时间 20:00 执行 `node scripts/generate-report.mjs`，以便在网站进程没有运行时生成档案。调度任务需要在使用者自己的环境中配置，不会随 Git 仓库自动创建；运行中的网站已有独立定时器。
- 手动生成一份日报而不启动网站：`npm run report`。退出码 1 表示行情不可用或只能保留旧行情；具体看输出的 `status` 和 `warnings`。
- 当前版本为本地网站。要在关机时继续更新、或通过公网长期访问，需另行部署到持续在线的服务器。

## 内容与统计口径

### 行情

Yahoo Finance 提供标普 500、纳斯达克综合、道琼斯和 VIX，以及约 80 只固定重点股与当日筛选器提供的涨跌/活跃候选。候选数量随来源而变，覆盖范围会显示在表格下方。

严格使用**最近一个已完成的纽约常规交易日**的两日收盘价计算涨跌幅，盘中筛选器的当前涨跌幅不会充当上一交易日数据。周末、NYSE 常规节假日、提前收盘和纽约夏令时均按交易日规则处理，临时特殊休市不在规则内。

异动口径：绝对涨跌幅至少 3%、成交量超过 10 万股；分别展示涨幅和跌幅最多各 8 只。**这是采样股票池，非全美股排名**；股票池之外的异动可能缺失。

### 异动分析

显示相对标普的强弱、对比此前最多 20 个交易日均量的量比，以及从 Yahoo Finance / Google News RSS 获取的公司相关新闻。新闻窗口从前一交易日收盘到目标交易日收盘，排除收盘后才发布的内容。

原因分类根据相关新闻进行规则归类，并保留标题、发布时间与原链接；**相关资讯不等于已证实的因果关系**。缺少有效新闻时明确显示「待核实」。当前不使用付费研究终端或大模型生成事实性因果结论。

### 未来七日信号

窗口为当前北京时间自然日及之后六天，已过去的精确发布时间在重新采集时排除。

| 来源 | 内容 |
| --- | --- |
| BEA | GDP、个人收入与支出 / PCE 等官方日历 |
| BLS | CPI、非农、PPI、就业等官方 ICS 日历 |
| Census | 零售、耐用品、住房、贸易等发布安排 |
| Federal Reserve | FOMC 会议结束日期 |
| NYSE 规则 | 常规休市、提前收盘 |
| Nasdaq | 市值至少 100 亿美元及重点跟踪股的**预计**财报，最多 20 项 |

已知时刻按纽约夏令时换算为北京时间；全天休市和没有时刻的 FOMC 日期保留「美东日期」标记。财报只有盘前/盘后安排时不虚构精确时刻，盘后安排按北京时间次日展示；Nasdaq 日历不等于公司的最终确认。

影响级别和传导机制是规则解释，不是涨跌预测。范围不包含所有临时政策、突发地缘事件、公司临时公告、完整期权与财报日历。来源故障会显示状态，绝不填充模拟行情或伪造日历。

## 算法与验证边界

页面「分析方法」完整披露当前算法：事件日历规则分类、3% 价格异动门槛、相对标普强弱、历史均量比、相关新闻关键词分类，以及人工维护的 AI 产业映射。当前没有训练涨跌预测模型，没有经过回测的概率输出，没有目标价。“高影响”代表关注级别，不是统计胜率；原因分析不自动认定因果。

## LLM 双研究员

打开首页「LLM 研究室 → 模型设置」，填写 Base URL、接口类型、模型名称与 API Key，然后点击「生成 AI 解读」。支持 OpenAI Chat Completions 和 Responses API 两类协议，可接入 OpenAI、DeepSeek 和自定义兼容服务；模型名称与调用权限需与服务商实际支持的配置匹配。某些网关仅允许其列出的编程客户端，禁止网站、脚本或 SDK 直连；这类凭据无法直接作为本站的服务端 API 使用，需提供方开放相应权限。

当前预设：OpenAI `https://api.openai.com/v1` / `gpt-4.1-mini`；DeepSeek `https://api.deepseek.com` / `deepseek-flash`。不包含 API 额度。没有密钥时显示未配置，不调用外部模型，也不伪造生成结果。

工作流程：

1. 程序固定行情、日历与新闻证据，选择最多 8 项宏观/AI 相关事件和 8 只 AI 异动股。
2. 两位研究员并行调用同一配置模型：事件与产业链分析、AI 个股异动与风险分析。每次请求预算最多 30 秒。
3. 程序检查 JSON、原有个股与事件、来源编号，屏蔽不符合约束的价格、百分比、日期和额外网址。行情原值由代码保留，模型负责解释机制、条件情景、催化线索及风险。
4. 记录模型、提示词版本、证据截点、快照哈希与来源目录；按证据快照缓存，结果随同一份日报归档。部分分析师失败时会显示缺口。

来源编号合法不代表事实或因果已获证明；LLM 输出没有经过预测胜率回测。外部新闻只作为待核实材料，不执行其中的指令。

配置保存在 `data/reports/llm-config.json`，被 Git 忽略，网页状态接口不会返回密钥，浏览器不会把密钥写入 localStorage。该文件是本机明文配置，请使用操作系统文件权限保护。请求会把有限的公开证据包发送至所选模型服务商，可能产生 API 费用。

也可以用环境变量：复制 `.env.example` 为 `.env`，填写后通过 `node --env-file=.env server.mjs` 启动。已通过网页保存的本机配置优先于环境变量。

## 页面功能

市场概览、指数趋势切换、日期和事件类别筛选、领涨领跌筛选、股票代码/公司搜索、按绝对涨跌排序、详情与原文来源、浏览器本地关注列表、历史日报。

关注列表仅保存当前浏览器中标记的股票代码；页面展示这些股票在当日日报异动样本中的记录，不是完整的自选股实时报价系统。

## 接口

- `GET /api/dashboard`：当前快照及采集状态
- `POST /api/refresh`：异步刷新，202 响应；轮询 dashboard 的 `refreshing`
- `GET /api/reports`：日报档案索引
- `GET /api/reports/YYYY-MM-DD`：历史日报
- `GET /api/health`：服务与下次更新状态
- `GET /api/llm/status`：模型配置与运行状态，不返回密钥
- `POST /api/llm/config`：保存本机模型配置，不发起模型推理
- `POST /api/llm/analyze`：异步启动双研究员，202 响应，轮询 dashboard 的 `llm.status`

服务默认只监听 `127.0.0.1`，并验证 Host/Origin。公开来源可能限流、修改格式或暂时不可用；系统保留旧数据日期并显示错误，无商业实时行情 SLA。
